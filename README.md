# 🎮 ArcadeHub — Интерактивный веб-портал настольных и казуальных игр

Современный, производительный игровой веб-портал, созданный на **Next.js 15+ (App Router, React 19, TypeScript)**, **Tailwind CSS**, **Framer Motion**, **Zustand** и **Web Audio API**, полностью готовый к мгновенному деплою на платформу **Vercel**.

---

## 🌟 Особенности и стек технологий

* **Фреймворк:** Next.js 15+ (App Router, Server Components + Client Game Containers, React 19).
* **Стилизация & UI:** Tailwind CSS, Glassmorphism, Neon Glow эффекты, Lucide React иконки.
* **Анимации:** Framer Motion (плавное скольжение и слияние плиток, броски карт, всплывающие окна).
* **Звуковой движок (Zero MP3 Dependencies):** Процедурный Web Audio API синтезатор (`src/lib/sound.ts`) генерирует звуки кликов, переворотов карт, сирены UNO, бросков кубиков, бочонков лото, ударов шашек, слияния плиток и победных фанфар прямо в браузере без внешних тяжелых файлов.
* **Праздничные эффекты:** `canvas-confetti` (салюты, конфетти-пушки при победах).
* **Vercel Serverless Ready:** Каждая игра снабжена умными AI-ботами и локальным режимом (Pass & Play / Hotseat), а архитектура комнат изолирована через абстрактный адаптер (`src/lib/multiplayer-adapter.ts`).
* **Конфигурация Vercel:** Файл `vercel.json` с оптимизацией кэширования статики и заголовками безопасности (`nosniff`, `DENY`, `X-XSS-Protection`).

## 🚀 Запуск локально

1. Клонируйте репозиторий или перейдите в папку проекта:
```bash
cd games_online
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер разработки:
```bash
npm run dev
```

4. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

5. Проверка чистоты сборки (Production Build):
```bash
npm run build
```

## ☁️ Инструкция по деплою на Vercel

### Вариант 1: Через Vercel CLI (самый быстрый)

1. Установите Vercel CLI глобально (если еще не установлен):
```bash
npm i -g vercel
```

2. В корне проекта выполните команду:
```bash
vercel
```

3. Для финального продакшн-деплоя:
```bash
vercel --prod
```

### Вариант 2: Через GitHub Интеграцию

1. Создайте новый репозиторий на [GitHub](https://github.com/new).
2. Запушьте проект в репозиторий:
```bash
git init
git add .
git commit -m "feat: initial release of ArcadeHub games portal"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<ваш-репозиторий>.git
git push -u origin main
```
3. Откройте [Vercel Dashboard](https://vercel.com/new).
4. Импортируйте созданный репозиторий — Vercel автоматически определит **Next.js** и выполнит сборку на основе `vercel.json` и `next.config.ts`.
5. Нажмите **Deploy** — проект моментально станет доступен по глобальному HTTPS-адресу с CDN-кэшированием!
